## Project Goal

This project studies fast conjunction-risk screening for space objects.
Given the orbital elements of two satellites, the model estimates within a
48-hour prediction window:

- Whether the pair is dangerous.
- The true closest approach distance `Dc`.
- The true closest approach time `TCA`.

The current research direction uses a Transformer-style model with two tokens:
one token for satellite A and one token for satellite B.

## Repository Layout

- `01_generate_collision_data.py`
  - Generates high-precision layered training data.
  - Saves orbital-element inputs and true labels under `data/`.
  - Uses J2 numerical propagation plus coarse search and dense-output local
    refinement to compute true `Dc` and `Tc`.

- `02_train_transformer.py`
  - Trains the JAX/Flax Transformer model.
  - Reads `data/X_coe.npy` and `data/Y_reg.npy`.
  - Produces metrics, summaries, prediction demos, and report figures under
    `logs/`.

- `backup_code_version.py`
  - Copies `01_generate_collision_data.py` and `02_train_transformer.py` into
    `code_versions/` before risky edits.

- `make_daily_report.py`
  - Creates a daily experiment summary Word document under `daily_reports/`.

- `.gitignore`
  - Excludes generated data, models, logs, daily reports, code backups, Python
    cache files, and large numeric/model artifacts.

## Data Schema

Generated files are expected under `data/`:

- `X_coe.npy`: shape `[N, 12]`.
  - Satellite A: `a, e, i, Omega, omega, M`.
  - Satellite B: `a, e, i, Omega, omega, M`.

- `Y_reg.npy`: shape `[N, 3]`.
  - `Y[:, 0]`: true closest approach distance `Dc`, in km.
  - `Y[:, 1]`: true closest approach time `Tc`, in seconds.
  - `Y[:, 2]`: source/layer code.

- `Y_class.npy`: shape `[N]`.
  - `1` if true `Dc <= 10 km`, otherwise `0`.

- `group_id.npy`: identifies samples generated from the same constructed group.

The data directory is intentionally ignored by Git.

## Current Sample Generation Method

`01_generate_collision_data.py` uses layered data generation:

- `constructed_danger_0_5km`
- `constructed_danger_5_10km`
- `constructed_near_safe_10_30km`
- `constructed_mid_safe_30_100km`
- `random_background_low_high`

Constructed samples are generated by choosing an encounter geometry at a random
future time, propagating the states backward to the initial epoch, converting
states back to orbital elements, and then recomputing the true closest approach
over the whole 48-hour window.

The true labels are not taken directly from the constructed encounter time.
They are recomputed using:

1. J2 numerical propagation with `solve_ivp`.
2. Coarse search over the full 48-hour time window.
3. Selection of local low-distance candidate times.
4. `dense_output=True` plus `minimize_scalar` refinement around candidates.
5. Final selection of the global minimum distance candidate.

Accuracy of labels is more important than generation speed for this research.

## Current Model Method

`02_train_transformer.py` uses 18-dimensional input features:

- Each satellite has 9 features:
  - `a`
  - `e`
  - `i`
  - `sin(Omega), cos(Omega)`
  - `sin(omega), cos(omega)`
  - `sin(M), cos(M)`

The two satellites become two Transformer tokens of dimension 9.

The current time representation is:

- `Tref = 0.5 * (TA + TB)`
- `TCA = (K + phi) * Tref`

where:

- `TA` is satellite A's orbital period.
- `TB` is satellite B's orbital period.
- `K` is the reference-period index.
- `phi` is the phase inside that reference period.

The model predicts:

- danger classification
- dangerous-sample `Dc`
- `K`
- `phi`

The distance/time regression metrics are interpreted mainly on true dangerous
samples. When the model predicts a sample as safe, `Dc/Tc` is not treated as a
meaningful operational output.

## Important Constants

Keep physics constants consistent between data generation and training.

- `MU = 398600.4418` km^3/s^2 is the project baseline Earth gravitational
  parameter.
- If `MU`, `R_EQ`, or `J2` is changed in `01_generate_collision_data.py`, then
  the data should be regenerated and `02_train_transformer.py` should use the
  same constants.

Avoid changing constants just to call a library. Tiny constant differences can
change period-derived labels near bin boundaries.

## Editing Rules

- Use tiered version management instead of backing up every small edit.
- Small edits do not need a full copy backup. Examples:
  - single threshold changes
  - loss-weight tuning
  - print/log text changes
  - report figure label or metric-display changes
- For small edits, rely on Git diff and record the change in
  `code_versions/version_log.md` when it affects an experiment.
- Create a full backup only before risky or high-impact edits, including:
  - data-generation logic in `01_generate_collision_data.py`
  - model architecture changes
  - loss-function changes
  - label definition changes
  - major evaluation/metric logic changes
  - any edit the user explicitly asks to back up

Full backup command when needed:

```bash
cd /home/xiaohui/project/collision
/home/xiaohui/miniconda3/envs/jax_env/bin/python backup_code_version.py short_change_description
```

- Check Git status before and after edits:

```bash
git status --short --branch
```

- Do not commit or track:
  - `data/`
  - `models/`
  - `logs/`
  - `daily_reports/`
  - `code_versions/`
  - Python cache files

- Keep plots in English. Chinese labels in matplotlib previously caused font
  warnings and unreadable figures.

- Communicate code-change explanations to the user in Chinese.

- If the user's requested scientific idea is unreasonable, say so directly and
  explain why. Do not blindly implement a weak research direction.

## Current Research Priorities

The project is currently focused on:

1. Building reliable high-precision labels for `Dc` and `TCA`.
2. Keeping the input compact and explainable: orbital elements plus angle
   `sin/cos` expansion.
3. Improving dangerous-sample `D_MAE` and `T_MAE`.
4. Maintaining strong danger recall and low miss rate.
5. Producing clear report figures and daily experiment summaries.

Important metrics:

- `D_MAE`
- `T_MAE`
- danger recall
- false alarm rate
- miss rate
- F1
- `K` accuracy
- `phi` MAE
